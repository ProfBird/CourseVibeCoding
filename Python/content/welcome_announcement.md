# Welcome to CIS 195 - Web Authoring 1

Hi everyone,

Welcome to CIS 195! I'm Professor Bird, and I'm looking forward to our first class meeting. Here's what to know beforehand:

### What this course is about

You'll learn to build web pages with HTML and CSS — no prior coding experience needed. By term's end, you'll have designed and published your own multi-page website.

### Before we meet

- Read the syllabus: [https://lcc-cit.github.io/CIS195-CourseMaterials/CIS195_Syllabus.html](https://lcc-cit.github.io/CIS195-CourseMaterials/CIS195_Syllabus.html)
- Install Visual Studio Code (our editor for the term): [https://code.visualstudio.com/docs](https://code.visualstudio.com/docs)
- Post in the **Introductions** discussion board (see prompt below)

### Introduce yourself!

Head to the "Introductions" forum in Canvas and tell us:

1. Your name and what you'd like to be called
2. What you're hoping to get out of this course
3. Any past experience with coding or web design (none needed!)
4. One fun fact about yourself

### Day one

We'll cover the syllabus, grading, and labs, then get set up in VS Code before writing our first HTML. Just bring a laptop.

### A few logistics
